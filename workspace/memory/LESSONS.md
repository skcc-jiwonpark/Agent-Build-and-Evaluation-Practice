# Validated Lessons

여기에는 실제 실행 또는 평가로 확인된 교훈만 추가한다. 가설은 `DECISIONS.md`에
기록하지 않는다.

## 2026-09-30 — 방법론 논문은 합성 레시피가 아니다

합성 가능성 예측·재설계 논문은 후보의 우선순위와 배경을 제공할 수 있다.
그러나 Experimental section 또는 Supporting Information에 전구체·비율·조건이
직접 기록되지 않았다면 그 값은 `not reported`로 남겨야 한다.

## 2026-09-30 — 형식 검증은 모델 지시보다 강하다

출력 섹션과 근거 상태 표기를 코드로 검사하고, 실패 시 한 번만 수리하는 편이
프롬프트만 길게 만드는 것보다 누락을 줄인다. 반복 수리는 무한 루프를 피하기 위해
제한한다.
