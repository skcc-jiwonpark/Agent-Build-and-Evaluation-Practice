# Project Context

## 목표

이 프로젝트는 무기결정 또는 목표 조성의 합성 가능성을 문헌 근거로 검토할 때,
전구체 후보와 합성 조건을 재현 가능한 방식으로 정리하는 보조 에이전트다.

## 핵심 질문

- 어떤 전구체가 실제 문헌 실험에서 사용되었는가?
- 전구체의 역할·몰비·반응 온도·분위기·시간·후처리는 무엇인가?
- 상순도, 수율, 실패 조건, 제약은 무엇이며 어느 출처에 있는가?
- 서로 다른 논문이 충돌하거나 빠뜨린 정보는 무엇인가?

## 도메인 용어

- **전구체(precursor)**: 목표 물질을 만들기 위해 반응에 투입하는 출발 물질이다.
- **무기결정**: 금속·비금속·산화물·염 등 무기 성분이 규칙적인 격자 구조를 이룬
  고체 물질이다.
- **합성 가능성(synthesizability)**: 계산상 안정성만이 아니라, 실제 조건에서
  원하는 상을 만들 수 있는지에 관한 실험적 가능성이다.

## 현재 참고문헌의 위치

현재 두 PDF는 합성 가능성 예측 및 LLM 기반 재설계의 방법론 논문이다. 유용한
배경·후보 우선순위 근거는 제공하지만, 특정 목표 물질의 완전한 전구체 레시피로
취급하면 안 된다. 직접 실험 절차와 Supporting Information을 추가했을 때만
전구체 조건을 `confirmed`로 판정한다.

## 범위 밖

- 실험 지시서 작성, 실험 승인, 구매·발주 결정
- 출처 없는 물성·공정 조건 추정
- 안전성 또는 규제 적합성의 최종 판정
